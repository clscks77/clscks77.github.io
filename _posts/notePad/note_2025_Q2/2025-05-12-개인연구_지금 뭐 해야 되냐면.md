### 1.1 Cross-chain Bridge

- DeFi 서비스와 Cross-chain의 관계
    - 각 체인은 자체적인 규칙, 합의 메커니즘, 거버넌스 구조에 따라 작동하기 때문에 소통이 거의 불가능 함
    - 거의 모든 블록체인 네트워크는 자체 분산형 크로스 체인 브리지를 보유하고 있음
        - 블록체인 네트워크란?
    - Polygon 블록체인의 DeFi 프로토콜은 이더리움 블록체인에서 발행된 스테이블코인을 사용할 수 있음

- 대부분의 bridge는 자산을 실제 이동시키지 않고, 원자산을 락(lock)하고 wrapped token을 발행하는 구조
    - "진짜 이동"이 아니라 IOU 기반의 대체 자산 전송임

- Types of Cross-Chain Bridges
    - Wrapped Tokens (wrapping model)
        - BTC를 이더리움에서 사용하기 위해 만든 WBTC (Wrapped BTC)
    - Atomic Swaps (=코인 스왑? 스왑은 Bridge랑 다른거 아닌가?)
        - 스왑은 AMM (Automated Market Maker; 시장 기반)을 기본 구조로 사용함
            - 유동성 풀(Liquidity Pool)에 두 자산(ETH/USDC)이 들어 있고, 사용자가 ETH를 넣으면, AMM 수식(x * y = k)에 따라 자동으로 대응되는 USDC를 산출함
    - etc

- 이건 좀 다른 관점이지만, Bridge 해킹 사고가 있었음 (Ronin bridge hack, $600 million, 22.03)
    - Most bridges are trusted setups, such as a multisig in which a handful of parties are designated to approve transactions and prevent fraud. 
    - On Ronin, five out of the nine validators used to approve transactions were hijacked after their private keys were stolen. 
    - This gave hackers the ability to validate transactions without oversight.

- Centralized bridge (CeFi Bridge): Binance Bridge, WBTC (BitGo)
- Decentralized bridge (DeFi Bridge): LayerZero, Axelar, Wormhole

- 하참, CCS 간 브릿지 논문이 있네 (*ZKP 관련)
    - zkBridge: Trustless Cross-chain Bridges Made Practical [CCS '22]
    - 자금세탁 관점에서 이걸 어떻게 못할려나◆

- Cross-chain 이동은 “같은 토큰 이름이지만 다른 체인”에 있는 자산 간의 전환
    -  Multi-chain 발행된 토큰 (USDC) 같은 경우는 Bridge 없이도 체인 간에 "토큰 스왑"이 가능
    -  Single-chain 토큰 같은 경우는, Wrapped Token 구조를 사용함
        -  Ethereum에만 있는 "TOKEN"을 Polygon으로 보내고 싶다 → Polygon에서 "Wrapped TOKEN" (wTOKEN)을 발행

| 구분     | LayerZero, Thorchain 등          | 1inch, Paraswap 등                    |
| ------ | ------------------------------- | ------------------------------------ |
| **역할** | Cross-chain 통신/스왑 인프라           | 단일 체인 혹은 multi-chain DEX 유동성 집계      |
| **분류** | **Cross-chain Liquidity Layer** | **DEX Aggregator**                   |
| **예시** | LayerZero, Thorchain, Li.Fi     | 1inch, Paraswap, CowSwap             |
| **기능** | 체인 간 스왑/메시지 전달 (ex: ETH ↔ BNB)  | 같은 체인 내 최적 스왑 경로 찾기 (ex: ETH ↔ USDC) |
| **특징** | 체인 간 브리지 & 유동성 추상화              | 라우팅 알고리즘, 가격 최적화                     |

- 1inch는 **한 체인 내에서 최적의 스왑 경로를 찾음**
- Thorchain, LayerZero는 **체인 간의 자산 이전 자체를 가능하게 함**

- **유동성(Liquidity)**
    - 어떤 자산을 시장 가격에 가깝게 빠르게 사고팔 수 있는 정도
    - DEX에서는 **유동성 풀(liquidity pool)**에 예치된 자산이 많을수록 유동성이 높다고 말함
        - Uniswap의 ETH/USDC 풀에 1억 달러가 있으면, 누구든지 큰 금액을 거래해도 가격이 크게 움직이지 않음 → 유동성이 높음
        - 반대로 유동성이 적은 풀에서는 조금만 거래해도 가격이 크게 변동 → 유동성이 낮음
- **슬리피지(Slippage)**
    - 사용자가 예상한 가격과 실제로 체결된 가격 사이의 차이
        - 예상: 1 ETH = 2,000 USDC → 1 ETH를 사려 했음
        - 실제 체결: 1 ETH = 2,020 USDC (슬리피지 1%)
    - 거래량이 크면 풀 내 자산 비율이 바뀌기 때문에 가격이 바뀜
        - 즉, 유동성이 낮을수록 슬리피지가 더 심해짐
    - 따라서 라우팅 알고리즘으로 여러 풀에 분산 거래하여 슬리피지 최소화해야 하는 것
- **MEV(Maximal Extractable Value)**
    - 블록을 생성하는 주체(채굴자 or 검증자)가 트랜잭션 순서를 조작해서 추가 이익을 얻는 행위
        - 이걸.. 공격이라고 봐야 하나..? 이건 주가조작 같은 느낌인데
        - 기술적인 공격이라기 보다는, 법적&제도적으로 해결해야 하는 분야라는 생각?
            - 아닌가.. 기술로 해결할 수 있으면 좋은가..? 블록체인 목표는 탈중앙이니까..
        - 방어 기술이 있긴 하네
            - Private transaction relays (예: Flashbots Protect)
            - Batch auction 방식 (예: CowSwap): MEV 공격을 원천 차단
                - 좀 재밌어보이는데? ◆
- **풀 내 자산 비율이 바뀌면 왜 가격이 바뀌는가?**
    - AMM (Automated Market Maker): 가격 결정의 기본 논리는 풀의 자산 비율 기반
    - 코인의 가격은 거래소에서 AMM이라는 가격 결정 알고리즘을 통해 내부적인 풀 상태에 따라 자동 계산됨
    - 스마트 컨트랙트의 **수학적 수량 보존 규칙**에 의해, “사람이 먼저 ETH 빼고 나중에 돈 내는 구조”는 허용하지 않음

- BTC를 스마트 컨트랙트에서 쓰기 위해 ERC-20 형태로 포장 → WBTC, renBTC
    - ETH 체인 상에서 BTC처럼 사용 가능
    - WBTC → USDC 스왑 (Uniswap에서 가능)

- Ethereum 계열 = EVM 호환 체인(Base, BNB, Polygon, Optimism)
    - 비-EVM 체인 (Solana, Bitcoin, Aptos) → Uniswap 지원 불가
    - ETH ↔ Base는 특별히 "Layer2 간 전송" 또는 "rollup bridge"라고 따로 부름
        - Layer 2: Ethereum 메인 체인의 트래픽 과부하를 줄이기 위해, 트랜잭션을 별도 체인에서 처리하고 결과만 Ethereum에 올리는 확장성 솔루션
            - Ethereum은 높은 보안성은 있지만, 속도가 느리고 가스비가 비쌈
            - L2는 더 빠르고 싸게 처리함 → 이후 Ethereum에 결과 요약만 제출 (rollup)

| 용어               | 의미                          | 예시                                       |
| ---------------- | --------------------------- | ---------------------------------------- |
| **Layer 1 (L1)** | 독립된 블록체인                    | Ethereum, Bitcoin, Solana                |
| **Layer 2 (L2)** | 특정 L1 위에 구축된 보조 체인 (확장성 목적) | Arbitrum, Optimism, Base (모두 Ethereum 위) |
| **Cross-chain**  | 서로 독립적인 L1 간의 자산 전송         | Ethereum ↔ Solana, Ethereum ↔ Bitcoin    |
| **L2 Bridge**    | 같은 생태계 내 Layer 간 자산 이동      | Ethereum ↔ Base, Ethereum ↔ Arbitrum     |

- Solana, Bitcoin은 자체 보안 → Cross-chain
- Arbitrum, Base는 Ethereum의 보안에 의존 → Layer2 (not full cross-chain)

| 개념             | 설명                   | 예시                            |
| -------------- | -------------------- | ----------------------------- |
| **코인 (coin)**  | 자체 체인을 가진 자산         | BTC, ETH, SOL, BNB            |
| **토큰 (token)** | 다른 체인의 위에서 발행된 자산    | USDC (Solana), RAY, SRM       |
| **체인 (chain)** | 블록체인 네트워크 자체         | Ethereum, Solana, Avalanche   |
| **L2**         | L1 위에 올라가는 확장용 별도 체인 | Arbitrum (Ethereum의 L2), Base |
