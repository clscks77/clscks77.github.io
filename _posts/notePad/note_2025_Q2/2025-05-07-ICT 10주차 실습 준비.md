## CountVectorizer()

- CountVectorizer()는 bag-of-words 기반의 encoding & representation 방법
    - encoding: 문자열(text)을 숫자 벡터로 바꾸는 것
    - representation: 벡터 공간에서 문서를 표현하는 방식

## 이것 외에, 문장을 벡터로 만드는 방법
- Bag-of-Words 계열 -> Word2Vec 계열 -> LSTM 계열 -> Transformer 계열

- 기초적인 통계 기반 (Bag-of-Words 계열)

| 방법                           | 설명                                        |
| ---------------------------- | ----------------------------------------- |
| **CountVectorizer**          | 각 문서에서 단어의 **등장 횟수**를 세어 벡터로 표현. 순서 무시.   |
| **Binary Vectorizer**        | 단어의 \*\*존재 여부(0 또는 1)\*\*만 사용.            |
| **TF-IDF (TfidfVectorizer)** | 흔한 단어의 가중치를 낮추고, 희귀 단어에 높은 점수 부여. 정보량 반영. |


- 분산 표현 (Distributed Representation; Word2Vec 계열)

| 방법                             | 설명                                  |
| ------------------------------ | ----------------------------------- |
| **Word2Vec (Skip-gram, CBOW)** | 단어들을 밀집 벡터로 표현. 비슷한 단어는 비슷한 벡터.     |
| **GloVe**                      | 전역 동시 출현 행렬 기반으로 학습한 단어 벡터.         |
| **FastText**                   | Word2Vec 확장. 서브워드 정보 포함 (형태소 반영).   |
| **Doc2Vec**                    | Word2Vec 확장. 문서 단위 벡터 학습.           |
| **Average Word Embeddings**    | 문장을 구성하는 단어 벡터의 평균. 간단하지만 순서 정보 없음. |



- 문맥 기반 표현 (Contextual Embeddings)

| 방법                        | 설명                                       |
| ------------------------- | ---------------------------------------- |
| **ELMo**                  | 문맥에 따라 단어 벡터가 달라짐 (양방향 LSTM 기반)          |
| **BERT**                  | Transformer 기반. 문맥 반영, 양방향 의미 이해 가능      |
| **GPT, T5, RoBERTa**      | 문맥, 문장 구조, 단어 순서 등 완전 반영. 사전학습 + 파인튜닝 방식 |
| **Sentence-BERT (SBERT)** | 문장 전체를 고정 길이 벡터로 변환. 문장 유사도에 탁월          |



## Multinomial Naive Bayes와 Bernoulli Naive Bayes의 차이
- 입력 특성 (feature)의 분포 가정이 서로 다르다는 점
    - 타겟 레이블 개수(이진 vs 다중 분류)가 아님
    - MultinomialNB → count 기반
    - BernoulliNB → binary(존재 여부) 기반


| 항목         | Multinomial Naive Bayes         | Bernoulli Naive Bayes          |
| ---------- | ------------------------------- | ------------------------------ |
| 입력 특징값 (X) | 단어 **빈도(count)** or **TF-IDF**  | 단어 **존재 여부 (0 또는 1)**          |
| 분포 가정      | 다항 분포 (Multinomial)             | 베르누이 분포 (Bernoulli)            |
| 문서 길이 영향   | 있음 (길수록 count가 커짐)              | 없음 (단어가 나왔는지만 보면 됨)            |
| 벡터화 추천 방식  | `CountVectorizer(binary=False)` | `CountVectorizer(binary=True)` |
| 사용 사례      | 뉴스 분류, 감성 분석 (단어 빈도 중요)         | 스팸 필터, 키워드 감지 (존재 여부 중요)       |
